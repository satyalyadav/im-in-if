# I'm in if...

Personal agents help existing student friends turn a spark of interest into a workable social plan. The first build is a local movie-night outing for Cubbie Hackathon Track 2, with a build budget of 12 to 16 hours. See the [product brief](docs/product-brief.md) and [glossary](GLOSSARY.md).

## Current stage

This repository is in design and discovery. It does not contain a working product.
