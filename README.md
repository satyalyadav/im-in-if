# I'm in if...

Personal agents help existing friends turn conditional interest into an agreed social plan.

People often start planning a movie, restaurant visit, trip, or campus event, then lose momentum in the back-and-forth. This project explores how each student's personal agent can exchange relevant constraints with other students' agents to help the group make a plan.

## Current stage

This repository is in design and discovery. It does not contain a working product.

## Context

This project is for Cubbie Hackathon Track 2, with a build-time budget of 12 to 16 hours.
